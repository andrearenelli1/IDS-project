# Distributed Multi-Drone ARTVA Search & Rescue in GPS-denied Conditions

**Course:** Intelligent Distributed Systems — University of Trento  
**Authors:** Andrea Renelli, Luca Zanolini

A fully distributed multi-drone simulation for avalanche victim search using ARTVA (457 kHz magnetic beacon) sensors, with no central coordinator and no external positioning (GPS-denied). Each drone runs a five-state FSM driven by MPC, with Extremum Seeking for gradient ascent toward the signal maximum and a cooperative Particle Filter for 3-D victim localization. Positioning is maintained by a cooperative inertial/UWB/LiDAR filter (IMDCL) in the absence of GPS.

The system is evaluated over **12 420 Monte Carlo runs** on real alpine terrain (TINItaly DEM), sweeping fleet size, ARTVA noise level, UWB communication radius, odometry noise, and terrain patch.

## Quick start — single run

```bash
# Default parameters from config.py (3 drones, 200×200 m, seed 42)
python main.py

# 5 drones, 3-D animation
python main.py --n 5 --steps 600 --animate

# Save diagnostic plots to figures/
python main.py --n 3 --seed 42 --save-figs

# Replay a specific sweep scenario
python main.py --n 4 --noise 1e-6 --rc 80 --area 100 \
               --victim-x 45.0 --victim-y 80.0 --victim-depth 2.5 \
               --ws 0.60,0.45 --animate
```

### CLI options

| Option | Default | Description |
|---|---|---|
| `--n` | `config.N_DRONES` | Number of drones |
| `--agl` | `config.AGL_HEIGHT` | Flight height above ground [m] |
| `--steps` | `config.N_SIM` | Simulation steps (1 step = 0.1 s) |
| `--seed` | `42` | Random seed |
| `--noise` | `config.ARTVA_NOISE_STD` | ARTVA additive noise std |
| `--rc` | `config.IMDCL_COMM_RADIUS` | UWB communication radius [m] |
| `--area` | `config.AREA_SIZE_M` | Workspace side [m] |
| `--victim-x` | random | Victim x in workspace [m] |
| `--victim-y` | random | Victim y in workspace [m] |
| `--victim-depth` | `config.VICTIM_DEPTH` | Burial depth [m] |
| `--ws` | `0.60,0.58` | DEM patch centre as `row_frac,col_frac` |
| `--animate` | off | Show live 3-D animation |
| `--save` | off | Save animation to `mission_animation.mp4` |
| `--save-figs` | off | Save PNG plots to `figures/` |

## Reproducing the paper results

### Option A — use the pre-computed CSV

All 12 420 runs are already stored in `results12420.csv`. To regenerate every figure from the report:

```bash
python plot_results.py results12420.csv
```

Figures are saved to `figures_sweep/`.

### Option B — rerun the full sweep

> **Warning:** the full sweep takes several hours even with many workers (≈12 420 runs × ~60 s each). The sweep is fully resumable: if interrupted, re-running picks up from the last completed row.

```bash
# Launch with 8 parallel workers (adjust to your machine)
python run_experiments.py --workers 8 --out results.csv

# Monitor progress (runs print to stdout when verbose=True)
python run_experiments.py --workers 1 --verbose
```

The sweep grid is defined at the top of `run_experiments.py`:

| Parameter | Values |
|---|---|
| Area size | 100 m, 200 m |
| Fleet size | 3, 4, 5 drones |
| ARTVA noise std | 1×10⁻⁷, 1×10⁻⁶, 1×10⁻⁵ |
| Odometry noise | 0.05 m/s², 0.10 m/s² |
| UWB comm. radius | 25 m, 60 m, 120 m |
| Terrain patches | 5 distinct DEM sub-areas |
| Victim positions | 10 random per combination |

Total: 2 × 3 × 3 × 2 × 3 × 5 × 10 = **5 400 base combinations** × replications = **12 420 runs**.

After the sweep completes, generate figures:

```bash
python plot_results.py results.csv
```

## System overview

### Five-state FSM (per drone)

```
SEARCH ──→ TRACK ──→ STOP ──→ FINAL_ORBIT
              │                ↑
              └──→ SUPPORT ────┘
```

1. **SEARCH** — adaptive lawnmower pattern. Lane spacing derived at runtime from the detection threshold so full area coverage is guaranteed.
2. **TRACK** — Extremum Seeking (Azzollini et al., 2021, eq. 11–13) drives the drone toward the signal maximum; Particle Filter is initialized.
3. **STOP** — drone hovers at the signal peak; recruits two partners via min-consensus over the UWB network.
4. **SUPPORT** — recruited drones orbit the STOP drone (one CW, one CCW) at the estimated signal-isoflux radius, feeding diverse angular measurements to the cooperative PF.
5. **FINAL_ORBIT** — once all PF-active drones reach STOP, each flies 6 waypoints around the current PF estimate to refine depth estimation before delivering the final position.

### Dynamic detection thresholds

Thresholds are not hardcoded. At startup each drone takes 20 ARTVA samples and the fleet agrees on a shared noise estimate via average-consensus:

```
τ_detect = max(μ̂ + 5σ̂,  m / r_ES³)      r_ES = 50 m
τ_stop   = m / r_found³                   r_found = 10 m
```

The physics floor `m / r_ES³` prevents triggering TRACK from outside the ES convergence basin under very low noise.

### Success criterion

A run is **found** when at least one PF-active drone has a 95 % confidence ellipse (drift-corrected by IMDCL) that **contains the victim** in the XY plane **and** whose area is below 78.5 m² (equivalent to a 5 m radius circle), within the 600 s deadline.

### Key algorithms

| Module | Algorithm |
|---|---|
| `mpc_drone.py` | Linear MPC via CasADi (N=20, QP at each step) |
| `imdcl.py` | Distributed cooperative Kalman filter — inter-drone UWB ranging + LiDAR altitude |
| `pf.py` | 3-D Particle Filter with ARTVA dipole likelihood, LiDAR ground constraint, and cooperative measurement fusion |
| `drone_agent.py` | Five-state FSM + Extremum Seeking + min-consensus partner selection |

## Configuration

All parameters are in `config.py`. Key groups:

- **Workspace / flight:** `AREA_SIZE_M`, `AGL_HEIGHT`, `LIDAR_SIGMA`
- **ARTVA model:** `ARTVA_MOMENT`, `ARTVA_NOISE_STD`, `VICTIM_DEPTH`
- **Thresholds:** `ES_DETECT_MAX_R`, `FOUND_RADIUS`, `N_NOISE_CALIB_SAMPLES`
- **Extremum Seeking:** `ES_ALPHA_MAX`, `ES_OMEGA`, `ES_KAPPA`, `ES_LAMBDA`
- **MPC:** `DT_MPC`, `N_MPC`, `A_MAX`, `V_MAX`
- **IMDCL:** `IMDCL_SIGMA_ACC`, `IMDCL_COMM_RADIUS`, `IMDCL_R_MEAS_STD`
- **Particle Filter:** `PF_N_PARTICLES`
- **Final orbit:** `FINAL_ORBIT_RADIUS`, `FINAL_ORBIT_N_WAYPOINTS`
